02 · Architecture & Control Flow

System Topology & Failure-Mode Lifecycles

End-to-end execution graph paired with nominal request flow and adversarial / degraded fault-handling paths.

flowchart LR
    U["Client Request<br/>(/query, /query/stream)"] --> G1["Input Guardrails<br/>(Injection, PII, Toxicity, Topic)"]
    G1 --> SC{"Chroma Semantic<br/>Cache (>= 0.92)?"}
    SC -- "Hit (1.4ms, $0)" --> OUT["Grounded JSON / SSE Stream"]
    SC -- "Miss" --> CL["Complexity Router<br/>(gpt-4o-mini vs gpt-4o)"]
    CL --> RET["ChromaDB Vector Store<br/>(k=3 + <<<BEGIN_CONTEXT>>> Fence)"]
    RET --> GEN["OpenAI Generation<br/>+ Phoenix OTel Spans"]
    GEN --> G2["Output Guardrails<br/>(Factuality, PII Scrub, Schema)"]
    G2 --> COST["Per-Request USD Ledger<br/>(data/cost_log.jsonl)"]
    COST --> OUT

✓ Nominal Production Request Path

  1. Client calls POST /query or SSE /query/stream; input_guards.py clears injection, toxicity, PII, and off-topic checks.
  2. semantic.py checks Chroma cache (cosine >= 0.92); cache hits return grounded JSON/SSE immediately in 1.4 ms ($0).
  3. On cache miss, classifier.py scores query complexity (simple -> gpt-4o-mini, complex -> gpt-4o) and retrieves k=3 fenced chunks.
  4. output_guards.py verifies groundedness & PII safety, emits Arize Phoenix OTel spans, and appends exact USD micro-cost to cost_log.jsonl.

✕ Adversarial, Policy & Fault-Handling Paths

  • Malformed catalog drop (bad_001.json) fails Pydantic schema validation in watcher.py and routes to data/quarantine/ with .error.txt diagnostics—zero index corruption.
  • Prompt injection or competitor/off-topic query is rejected at input_guards.py before embedding or LLM invocation.
  • Low-groundedness / hallucinated draft fails output_guards.py factuality threshold (tune_factuality_threshold.py) and returns a safe fallback.
  • Circular or upward layer import introduced by a developer fails the automated dependency-graph-forward-only AST gate.

04 · Engineering Trade-Offs (ADRs)

Why This Architecture Over Naive Prototypes?

Key architectural decisions balancing determinism, latency, cost, privacy, and operational maintainability.

Architectural Decision Naive Prototype Anti-Pattern Production Engineering Choice & Outcome
Embedded Chroma Semantic Cache vs. External Redis Stack Requiring a separate Redis Stack cluster just for vector caching, adding operational infra overhead and network hop latency. In-process Chroma cosine cache (>= 0.92) with TTL expiration: zero extra containers and 1.4 ms cache hits.
Tiered Complexity Routing vs. Single Frontier Model Sending 100% of FAQ traffic to gpt-4o, burning $0.0059+ on single-attribute weight/price questions. Pre-retrieval complexity routing to gpt-4o-mini saves 61.9% USD while preserving 1.000 golden-set faithfulness.
Hybrid Lexical/Regex + LLM Judge Guardrails Downloading multi-hundred-MB transformer guardrail weights at startup, causing cold-start timeouts and corporate proxy failures. Zero-latency deterministic regex/PII guards paired with configurable LLM factuality judging.
Dead-Letter Quarantine on Hot-Folder Ingestion Crashing the ingestion worker or silently indexing partial null fields when upstream catalog JSONs are malformed. Atomic schema check moving bad payloads to data/quarantine/*.error.txt while keeping the live index clean.
