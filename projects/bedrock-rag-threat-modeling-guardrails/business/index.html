02 · Architecture & Control Flow

System Topology & Failure-Mode Lifecycles

End-to-end execution graph paired with nominal request flow and adversarial / degraded fault-handling paths.

flowchart LR
    U["Streamlit Client"] --> H["AgentCore Harness<br/>(Claude Sonnet 4.5)"]
    H --> G["Bedrock Guardrail v1+<br/>(Prompt Attack, PII, Deny Topics)"]
    G --> IAM["Scoped IAM Execution Role<br/>(Explicit Deny Model/Guardrail Bypass)"]
    IAM --> GW["AgentCore Gateway<br/>(allowedTools=['northstar-kb___Retrieve'])"]
    GW --> KB["Bedrock Knowledge Base<br/>(30 Enterprise Docs · S3 + Vector Store)"]
    G --> CW["CloudWatch Logs Insights + Metric Alarm<br/>(NorthstarAssist-GuardrailInterventions-High)"]

✓ Nominal Production Request Path

  1. Employee submits benign internal policy question (e.g., hybrid-work policy) through the hardened AgentCore harness.
  2. Scoped IAM role permits northstar-kb___Retrieve against the 30-document S3 Knowledge Base and invokes Claude Sonnet 4.5 under active Bedrock Guardrails.
  3. Guardrail verifies response contains zero staff PII, credentials, or off-topic content and delivers grounded policy answer.
  4. Invocation metadata and guardrail trace status stream to CloudWatch /northstar-assist/bedrock-invocations.

✕ Adversarial, Policy & Fault-Handling Paths

  • T1_direct_injection & T3_off_topic attacks are stopped at Guardrail ingress (stop: guardrail_intervened, 0 KB retrieval calls).
  • T2_sensitive_pii & T5_paraphrased_pii retrieve internal docs containing staff contacts, which Guardrail post-filters intercept before output delivery.
  • Caller attempting direct bedrock:InvokeModel without guardrailIdentifier hits IAM Explicit-Deny (09_override_test.py).
  • >5 interventions/hour trips NorthstarAssist-GuardrailInterventions-High, triggering the 15-minute IR containment & kill-switch playbook.

04 · Engineering Trade-Offs (ADRs)

Why This Architecture Over Naive Prototypes?

Key architectural decisions balancing determinism, latency, cost, privacy, and operational maintainability.

Architectural Decision Naive Prototype Anti-Pattern Production Engineering Choice & Outcome
IAM Explicit-Deny on Unguarded InvokeModel vs. App-Config Only Configuring guardrailId only in application code—allowing any compromised role or misconfigured script to call InvokeModel raw. IAM condition/explicit-deny enforcement (09_override_test.py) guarantees requests without the approved guardrail fail at the AWS IAM control plane.
Multi-Run (3x) Paraphrase Red-Team Matrix vs. Single Prompt Check Testing one obvious 'Ignore previous instructions' string once and declaring RAG safe. 36-execution battery across T1–T5 (including paraphrased indirect PII extraction after KB retrieval) proving 100% deterministic guardrail_intervened.
Compensating S3 Versioning + IR Playbook for Indirect KB Poisoning Assuming runtime guardrails alone detect subtle factual poisoning inside S3 Knowledge Base documents. Documented architectural gap analysis + S3 ListObjectVersions / CloudTrail write auditing and 30-doc manifest verification in Task6b_IR_Playbook.md.

02 · Commercial Risk vs. Production Unlock

Why Prototype Pilots Stall — And How This Architecture Unblocks Launch

Translating engineering guardrails, determinism, and cost controls into executive deployment readiness.

✕ Why Cloud GenAI Pilots Stall in Enterprise Security Review

  • Configuring guardrailId only in application code lets misconfigured scripts or leaked roles call bedrock:InvokeModel raw.
  • Basic keyword filters miss paraphrased indirect PII extraction (T5) once internal S3 documents are retrieved into context.
  • Unbounded agent tool loops (12k+ tokens) expose the cloud account to denial-of-wallet billing spikes.
  • Missing STRIDE-ML threat models, ML-BOM inventories, and incident playbooks block enterprise procurement and ISO/SOC2 audits.

✓ Commercial Outcomes Delivered by This Architecture

  • Unblocks workforce-wide GenAI rollout with empirical 36/36 red-team proof across direct and paraphrased PII/secret probes.
  • Zero unguarded model execution: AWS IAM Explicit-Deny rejects any API call missing the approved Guardrail ARN.
  • Predictable blast radius: AgentCore gateway caps iterations (max 3), timeouts, and tool targets to prevent runaway spend.
  • 15-minute operational containment SLA backed by live CloudWatch metric alarms, Logs Insights queries, and S3 version recovery.
