✓ Nominal Production Request Path

  1. policy-extractor extracts structured insurance fields with Claude Haiku 4.5, runs blind second-model review (reviewer.py), and routes via 3-signal HITL router.
  2. mortgage-extractor executes a 2-pass classifier -> nullable doc-type schema -> deterministic Python YTD earnings validator (consistent: true, exit 0).
  3. supply-chain-risk ingests multi-source reader envelopes, deduplicates claims in all-MiniLM-L6-v2 vector memory, and corroborates dated supplier risks.
  4. calibration_report.py audits confidence vs. ground truth across every policy_type x field slice to tune auto-approve vs. human-review thresholds.

✕ Adversarial, Policy & Fault-Handling Paths

  • Source document missing endorsement section (POL-2025-009) classifies as missing_source and halts immediately after 1 call—zero wasted retry spend.
  • Perturbed paystub with -$1,250.00 line-item vs. YTD mismatch fails mortgage_extractor/validator.py deterministically (exit 1).
  • --simulate-timeout on a supply-chain feed degrades gracefully (exit 0), tagging [single source only] without polluting vector claim memory.
  • Umbrella policy exclusions with high model confidence (0.93) but 0.00 accuracy are caught by sliced Brier (0.865) and routed to mandatory human review.

04 · Engineering Trade-Offs (ADRs)

Why This Architecture Over Naive Prototypes?

Key architectural decisions balancing determinism, latency, cost, privacy, and operational maintainability.

Architectural Decision Naive Prototype Anti-Pattern Production Engineering Choice & Outcome
Sliced (policy_type x field) Brier vs. Aggregate Confidence Threshold Auto-approving any extraction with confidence >= 0.90 based on a healthy 0.291 global Brier score. Per-slice Brier evaluation exposes umbrella / exclusions (conf=0.93, acc=0.00, Brier=0.865) and forces targeted HITL escalation.
Error-Classified Retry (missing_source Halt) vs. Blind Exponential Backoff Retrying every failed extraction 4 times with higher temperature—quadrupling latency and inducing hallucinated values when source text is absent. Immediate 1-call halt on missing_source vs. targeted schema repair on format errors.
ReaderResult Timeout Envelope vs. Uncaught Gather Exceptions Failing an entire multi-source risk report or writing half-parsed rows into vector memory when one upstream feed times out. Isolated timeout envelopes degrade cleanly (exit 0), preserve clean vector state, and surface explicit [single source only] provenance.
Structured # Case Facts Header + Verbatim Active Window Summarizing the entire conversation history uniformly, losing exact active payment error codes and structured status enums (eval_control Q6 regression). 204-token top # Case Facts + summarized resolved threads + byte-exact active thread (56.8% reduction, 6/6 eval pass).
